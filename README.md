## About Me

- Student in **Systems Analysis and Development (ADS)**, aiming for a career in **software development**, with a preference for **backend**.
- Main ecosystem: **C# / .NET**: building REST APIs with ASP.NET Core and Entity Framework Core.
- Also studying **Machine Learning** with Python, applying it in hands-on projects.
